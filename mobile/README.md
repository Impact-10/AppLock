# Activity Locker — Flutter MVP

This is a minimal Flutter MVP skeleton for Activity Locker.

Prereqs:
- Flutter SDK (stable channel)
- Android Studio/Xcode for emulators

Run:
```bash
cd mobile
flutter pub get
flutter run
```

Notes:
- No API keys included.
- On-device ML Kit used by default for image labeling.
- Admin panel available via the overflow menu (stubbed credentials).
