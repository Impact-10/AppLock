# Version 1 Specification — AppLock (Gateway Model)

## Overview
AppLock is a Flutter app (Android + iOS) that acts as a gateway to locked apps. Users complete admin-assigned activities before accessing selected apps via intents or URL schemes.

## Roles
- **Admin**: Creates users, assigns activities, locks/unlocks users
- **User**: Logs in, completes activities, accesses selected apps through the gateway

## User Flow
1. **First Launch**: Choose Admin or User role
2. **Login**: 
   - Admin: Email + password
   - User: User ID + password (generated by admin)
3. **Lock Status Check**:
   - If locked OR new day: Show activities screen
   - If unlocked today: Show gateway screen
4. **Activities** (if locked or new day):
   - Display sequentially
   - User takes photo for each (any image accepted)
   - On completion of all: Set `isLocked = false`, `lastUnlockedDate = now`
5. **Gateway Screen**:
   - Grid/list of selected apps
   - Tap to open via platform intent (Android) or URL scheme (iOS)

## Admin Flow
1. **Dashboard**: List users under admin
2. **Create User**: System generates User ID and password
3. **User Details**:
   - Assign activities
   - Lock/Unlock user
   - View completion status

## Data Model (Firestore)
```
admins/{adminId}
  users/{userId}
    - name: string
    - userId: string
    - email: string
    - isLocked: boolean
    - activities: [ { description, status } ]
    - selectedApps: [ { label, package, scheme } ]
    - lastUnlockedDate: timestamp (nullable)
    - createdAt: timestamp

userProfiles/{userId}
  - adminId: string
  - userId: string
  - name: string
  - createdAt: timestamp
```

## Backend
- Firebase Auth (email/password)
- Firestore (data store, source of truth)
- No Cloud Functions in v1
- Client-side daily reset logic (compare dates)

## Tech Stack
- Flutter (Dart)
- Riverpod (state)
- Hive (local cache)
- Firebase Auth + Firestore
- image_picker (camera)
- Poppins font

## Platform Notes
- Android: Uses intents to open apps
- iOS: Uses URL schemes to open apps
- App mapping maintained locally in Firestore
- No OS-level app blocking

## Permissions (v1)
- Camera (photo for activities)
- Photo library access

## Deployment
- Spark plan (Firebase free tier)
- No Blaze billing required in v1
